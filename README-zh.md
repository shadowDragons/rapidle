# Rapidle

[English](README.md) | [中文](README-zh.md)

一款极简的桌面效率工具，支持记忆片段、快捷访问链接、请求第三方工具API、快速打开系统应用。

![rapidle-demo.gif](https://85b83fbf.cloudflare-imgbed-3ws.pages.dev/file/1737688882415_rapidle-demo.gif)

## 特性

- 🚀 随手可用：任何时候都可以呼出Rapidle，用完即走
- 📝 记忆片段：快速记录笔记和代码片段
- 🔗 快捷链接：收藏并快速访问常用网址
- 🛠️ API集成：连接第三方工具
- ⚡ 系统启动器：快速打开系统应用

## 即将支持

- 📋 剪切板历史记录
- 🔄 多端同步

## 快速开始

### 安装依赖

```bash
pnpm install
```

### 开发环境

```bash
pnpm run dev
```

### 打包

macOS版本：

```bash
pnpm run build:mac
```

Windows版本：

```bash
pnpm run build:windows
```
