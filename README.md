# Rapidle

[English](README.md) | [中文](README-zh.md)

一个简约的桌面效率工具，支持记忆片段、快速访问链接、第三方 API 请求和快速启动系统应用。

![rapidle-demo.gif](https://85b83fbf.cloudflare-imgbed-3ws.pages.dev/file/1737688882415_rapidle-demo.gif)

## 功能特点

- 🚀 即时访问：随时随地召唤 Rapidle
- 📝 记忆片段：快速笔记和代码片段
- 🔗 快速访问链接：书签和访问常用网址
- 🛠️ API 集成：连接第三方工具
- ⚡ 系统启动器：快速打开系统应用

## 即将推出

- 📋 剪贴板历史
- 🔄 多设备同步
- 📸 截图和图片粘贴支持

## 快速开始

### 安装

```bash
pnpm install
```

### 开发

```bash
pnpm run dev
```

### 构建

macOS 版本：

```bash
pnpm run build:mac
```

Windows 版本：

```bash
pnpm run build:windows
```
